# Changelog

## [1.0.0] — 2026-10-22
### Added
- First release. Kent's Repertory (1897), complete: 74,667 rubrics, 735,500
  graded remedy links, 669 remedies, 41 chapters.
- Search over rubric paths, narrowest rubrics first; chapter browse; narrow-only filter.
- Case builder with rubric list, grade-weighted **Analysis** and a remedy × rubric **Matrix**.
- Filters: minimum grade, "cover all rubrics".
- Export: plain text, CSV, JSON, print/PDF. Case persists in localStorage.
- Offline-first: single self-contained HTML file, PWA manifest and service worker.
- Dark/light theme, high-contrast, keyboard shortcuts, screen-reader friendly.
